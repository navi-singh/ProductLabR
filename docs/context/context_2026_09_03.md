# ProductLabR — Project Context
**Generated:** 2026-09-03

## Current product

ProductLabR is a content-driven editorial product-review site for consumer electronics
and outdoor gear. Reviews are Markdown files with YAML frontmatter, rendered by Next.js
App Router and statically exported to GitHub Pages. Revenue surfaces are Google AdSense
and affiliate retailer links.

## Architecture

- **Framework:** Next.js 16 App Router, React 19, TypeScript 5 strict.
- **Rendering:** build-time static export; dynamic article and category routes enumerate
  parameters during the build.
- **Content:** `posts/<category>/<slug>.md`, loaded by `lib/Posts.ts`.
- **Markdown:** `lib/markdown.ts` uses `marked`, strips raw HTML, adds styled markup,
  prefixes local image URLs with `withBasePath()`, and formats image-credit captions.
- **Styling:** Tailwind CSS 3.4, CSS variables, and the shared design tokens in
  `styles/theme.css`.
- **Deployment:** GitHub Actions builds `out/` and deploys it to GitHub Pages.
